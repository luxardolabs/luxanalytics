# 2026.10.1 — 2026-10-10

A small release for people who run their own LuxAnalytics server: one setting fewer, and tracing that works and is set up like everything else.

Surfaces in this file are plain labels: `Self-hosting` (running your own server). This app does not render release notes in its UI, so there is no badge registry to wire.

## IMPROVED

- **One setting fewer** `Self-hosting` — `DATABASE_URL_SYNC` is no longer needed. A settings file that still has it keeps working.
- **Tracing set up like every other setting** `Self-hosting` — The tracing address and service name can now go in your settings file, and the service name defaults to `luxanalytics`.
- **Cleaner logs** `Self-hosting` — Web server log lines no longer contain terminal colour codes.

## FIXED

- **Database tracing** `Self-hosting` — With tracing on, database queries showed up in no trace; each query now appears as its own step.
