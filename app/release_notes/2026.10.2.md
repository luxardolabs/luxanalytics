# 2026.10.2 — 2026-10-12

A security release for the dashboard: signing out now really signs you out, and the dashboard turns away requests from other sites.

Surfaces in this file are plain labels: `Dashboard` (the web dashboard) and `Self-hosting` (running your own server). This app does not render release notes in its UI, so there is no badge registry to wire.

## IMPROVED

- **Logging out signs out everywhere** `Dashboard` — Logging out now ends every signed-in session, so a copy of your sign-in cookie stops working too.
- **Requests from other sites are turned away** `Dashboard` — A page on another site can no longer submit the login form or sign you out on your behalf.
- **Clear message when sign-in is unavailable** `Dashboard` — If the server can't check sessions, the login page says so, instead of sending you back to it with no explanation.
- **You land where you were going** `Dashboard` — After signing in you return to the page you asked for, filters included.
- **Your server's addresses are required** `Self-hosting` — The allowed-hosts setting must now list the addresses your server answers on, or it won't start. See the settings template.
- **Dashboard sign-in needs Redis** `Self-hosting` — Signing in to the dashboard needs a working Redis. Event collection does not.

## FIXED

- **Long sessions showed the wrong totals** `Dashboard` — A session with more than 200 events showed 200 events and a duration that stopped at the 200th. It now shows the real count and length, and says when the list shows only the first 200 events.
