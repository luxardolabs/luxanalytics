# 2026.10.0 — in preparation (not yet released)

A security and reliability release: your events are counted once, kept when a phone's clock is wrong, and carry their full device details, and the dashboard is locked down.

Surfaces in this file are plain labels: `Dashboard` (the web dashboard) and `Ingest API` (where your apps send events). This app does not render release notes in its UI, so there is no badge registry to wire.

## NEW

- **Full device details on every event** `Dashboard` — Each event now keeps the device type, build number, screen size, language, time zone and TestFlight flag it was sent with, not just the device's latest values.
- **Events are counted once** `Ingest API` — When the app resends a batch after a dropped connection, events it already sent are recognised and not stored twice.
- **Daily backups** `Dashboard` — Your event data is backed up every day, and the newest two weeks of backups are kept.
- **Event format guide** `Ingest API` — One page describes exactly what to send, how to sign it, and what each answer means.

## IMPROVED

- **Safer sign-in** `Dashboard` — Your session cookie is always sent over a secure connection, repeated wrong passwords are slowed down, and after you sign in you only ever land on a page of this site.
- **Private statistics** `Dashboard` — The summary statistics are visible only after you sign in.
- **Clearer errors** `Dashboard` — When something goes wrong loading a panel, you now see a message with a reference to quote instead of a blank or half-loaded panel.
- **Whole-history numbers** `Dashboard` — A user's errors and screens, and a property's counts and values, now cover all of their events instead of only the most recent ones.
- **Reliability** `Dashboard` `Ingest API` — Lots of behind-the-scenes security, stability and speed work, including faster event intake.

## FIXED

- **Wrong phone clocks** `Ingest API` — A phone whose clock was set ahead lost all of its events; they are now kept and stamped with the time they arrived, and so are events from a clock reset to long ago.
- **Rejected events** `Ingest API` — A badly formed event now gets a clear "rejected" answer instead of a server error, so the app stops retrying it.
- **"All time" range** `Dashboard` — Choosing All showed errors or empty panels on several pages; it now shows your whole history everywhere.
- **Deactivating an app** `Dashboard` — Turning an app off from its edit panel failed with an error; it now saves.
- **Duplicate App ID** `Dashboard` — Creating an app with an App ID already in use showed nothing; you now see why it was refused.
- **Links with special characters** `Dashboard` — A user, session or property name containing a slash or question mark broke its page or link; it now opens.
- **TestFlight devices** `Dashboard` — A device could lose its TestFlight flag, OS version or language when one of its events left them out; it now keeps them.
- **Searching for symbols** `Dashboard` — Searching events for text that contains a percent sign or an underscore now finds exactly that text, instead of matching far too much.
