# 2026.11.0 — 2026-11-18

A security and reliability release: your dashboard is harder to attack, your event data stays with the right app, and a busy or misbehaving app can no longer flood the server.

Surfaces in this file are plain labels: `Dashboard` (the web dashboard), `Ingest API` (where your apps send events) and `Self-hosting` (running your own server). This app does not render release notes in its UI, so there is no badge registry to wire.

## NEW

- **Fair-use limits on incoming events** `Ingest API` — Each device, network address and app has its own event budget. One noisy device or app slows only itself, and a request that fails to save gives its budget back.
- **Repeated requests are stored once** `Ingest API` — If a signed request is sent twice, for example by a network retry, its events are saved only once.
- **Inactive stops every app key** `Ingest API` — Marking an app Inactive now turns away its signed requests too, not only its DSN.

## IMPROVED

- **Logging out ends every session** `Dashboard` — Logging out signs out every browser at once, and it keeps working even if the cache server restarts. You will need to sign in again once after this update.
- **Each page shows one app's data** `Dashboard` — Event search, journey exit screens, and the user and session panels show only the app you selected, and links in them open that app's row.
- **Deleted apps stay deleted** `Dashboard` — A deleted app disappears from the app menu, and its app ID can't be reused, so a new app never inherits an old app's events.
- **Clearer app forms** `Dashboard` — Mistakes in the app forms, such as a blank name, an ID already taken, invisible characters or an over-long field, show a message on the form instead of an error page.
- **Safer server settings** `Self-hosting` — The server checks its settings at startup and refuses to start, without printing secrets, when one is missing or unsafe. Production now needs a session secret, your proxy's exact address and your public host name.
- **Long screen and button names are kept** `Ingest API` — An event with a very long screen, operation or button name is saved with the name cut to 2000 bytes, instead of being turned away.
- **Reliability** `Dashboard` — A slow or unavailable cache server no longer floods the logs or stalls pages, and the health check now reports it correctly.

## FIXED

- **Journey tooltip could run scripts** `Dashboard` — A screen name sent by an app could run code in your browser when you hovered over the journey heatmap. It now always shows as plain text.
- **Pages that errored on unusual data** `Dashboard` — These no longer break with an error page: the performance page with fractional durations, pages showing events with unusual properties, and very large page or time-range numbers in a link.
- **Login page could show any message** `Dashboard` — A link could make the login page show text of the sender's choosing. It shows only its own messages now, and the "You have been logged out" confirmation appears again.
- **Filters lost when switching time ranges** `Dashboard` — Time ranges keep event and app filters whose names contain characters such as `+`, `&` or `#`.
- **Retry timing** `Ingest API` — The "try again after" time on a rate-limited response is no longer a second too short.
